## 文档约定

所有入库文档必须脱敏。脱敏清单和提交格式见 `AGENTS.md`。

文档标注两类事实：

- **界面实测**：截图中直接可见的内容，保留原文。
- **源码位置**：按界面术语定位到的包或目录，属查找入口，不承诺行号精确。

界面版本与源码版本可能不同。界面截图为 `0.2.2-rc.5`。做行号级核对前，先 checkout 对应 tag。
